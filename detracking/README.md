# 十年的一個問題 · Ten Years of One Question

一個關於〈十二年國教免試入學的政策效果〉這篇論文的公開科普網站，兩頁：

| 檔案 | 內容 |
|---|---|
| `index.html` | **研究在說什麼** — 從十二年國教自己寫下的政策目標出發，問它十二年後做到了什麼、代價是什麼。含「做到了①均質化／做到了②機會均等／代價」的架構與七張圖。 |
| `story.html` | **十年的故事** — 從 2015 年的研究所申請計劃書，到 2026 年刊出。含五個版本的文字重疊矩陣與對照表、那封 email、審查過程中退讓與守住了什麼。 |
| `style.css` | 共用樣式 |
| `app.js` | 共用行為：中英切換、章節導覽的高亮、時間軸收合、所有圖表 |

## 怎麼放到 GitHub Pages

這四個檔案是純靜態的，沒有任何相依套件或建置流程。

**方法一：放在現有網站的子目錄**（推薦）

```bash
# 在你的 yungyutsai.github.io repo 裡
mkdir -p detracking
cp index.html story.html style.css app.js detracking/
git add detracking && git commit -m "Add detracking explainer" && git push
```

網址會是 `https://yungyutsai.github.io/detracking/`。
記得在主網頁（例如 Research 頁）加一個連結指過來。

**方法二：獨立的 repo**

新建一個 repo，把四個檔案放進根目錄，到 Settings → Pages 選 `main` 分支的根目錄即可。

## 語言切換怎麼運作

沒有用 localStorage（GitHub Pages 上沒問題，但為了在任何嵌入情境都能運作）。
語言存在網址裡：

- `index.html` → 中文
- `index.html?lang=en` → English

切換按鈕會改寫網址並更新頁內所有連結，所以跨頁瀏覽時語言會被保留。
如果你想直接分享英文版，複製帶 `?lang=en` 的網址即可。

## 導覽與時間軸

- **章節導覽列**：兩頁的頁首下方有一條章節列，會跟著捲動固定在畫面上方，並自動高亮目前所在章節。要增刪章節，改 HTML 裡 `.secnav-links` 的連結，並確保對應的 `<h2>` 有相同的 `id`。
- **時間軸預設收合**：故事頁的十年時間軸預設只顯示每格的標籤與標題，點標題展開；上方有「全部展開／全部收合」。收合是 JS 加上去的，關掉 JS 時會全部顯示，內容不會遺失。

## 幾個可以自己改的地方

- **左上角的姓名**：連到 https://yungyutsai.github.io ，開新視窗。頁首選單裡原本的「個人網頁」項目已移除。
- **論文連結**：已指向 https://www.rchss.sinica.edu.tw/jssp/journals/3791 （出現在兩頁的 byline、footer 與故事頁時間軸）。若日後有 DOI，全域取代該網址即可。
- **email 寄件者的名字**：目前以「一位口試委員（教育經濟學者）」代稱。若你已徵得同意，改 `story.html` 的 `.email-h` 區塊即可。
- **配色**：`style.css` 最上面的 `--s1` 到 `--s4`。目前這組通過色盲可辨識度檢查（最差相鄰配對 CVD ΔE 9.1），換色前建議重新檢查對比。
- **深色模式已移除**：網站固定為淺色，不隨系統設定改變。
- **加分享圖**：在兩頁的 `<head>` 加一行 `<meta property="og:image" content="...">`，社群分享時才會有預覽圖。
